\section*{Research Overview}
\begingroup\setlength{\emergencystretch}{3em}\looseness=-1\lsstyle
My research focuses on \textbf{efficient systems for AI agents}. This line of work began with \mbox{\link{https://thunderagent.ai/}{ThunderAgent}}, which studies abstractions for agentic LLM inference scheduling. Building on this perspective, \mbox{\link{https://inference-rsi.com/}{Evolving Infra}} explores adaptive infrastructure for dynamic agent workloads, while \mbox{\link{https://flashstates.ai/}{FlashStates}} \mbox{investigates} how hybrid attention architectures reshape memory management in agentic inference systems.
